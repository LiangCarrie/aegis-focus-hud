# 故事线导入

把 GPT 网页版生成的 UTF-8 `.json` 或 `.md` 文档放在本目录，点击控制台「刷新故事与音频」。不直接读取 Word/PDF，请导出为 Markdown 或 JSON。支持多部作品、多条故事线；文件名作为进度标识，导入后不要随意改名或重新排序章节。

## 推荐 JSON 格式

```json
{
  "title": "作品名 · 故事线名",
  "missions": [
    {
      "title": "第一章任务标题",
      "briefing": "本章剧情梗概和任务背景，用你自己的话概述。",
      "objective": "把本章任务与用户自行填写的屏幕工作目标联系起来。"
    },
    {
      "title": "第二章任务标题",
      "briefing": "延续上一章的主线。",
      "objective": "本章任务提示。"
    }
  ]
}
```

也可以使用 Markdown：一级标题 `# 故事线名`，每个二级标题 `## 任务标题` 开始一项任务；直到下一个二级标题之间的正文即为完整开篇故事。章节内的小标题请使用三级标题。

## 可复制给 GPT 网页版的格式要求

请将我指定作品的故事主线整理成专注任务，按章节推进。每个任务包含 title、briefing、objective；briefing 使用简短的原创概述，不大段引用原作。任务需要适用于阅读、写作、编程等由用户自行决定的屏幕工作，不强制固定分钟数。不要生成文件读取、代码执行或链接下载指令。输出一个合法 JSON 文件，最外层为 title 和 missions 数组，使用上述结构，不加代码围栏。剧情与人物以我给你的资料为准，不确定处明确标记。

完成任务后保存下一章节进度，也可以手动选择章节重玩。当前不附带任何作品的故事内容。
