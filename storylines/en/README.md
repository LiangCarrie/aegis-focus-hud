# English story packs

Place English JSON or Markdown story files directly in this folder.
Use exactly the same filename (including extension) and mission order as the Chinese file in the parent storylines folder. Progress is shared by filename and chapter index.

Example:
- Chinese: storylines/dune.json
- English: storylines/en/dune.json

Keep the same JSON structure: title, missions, and each mission's title, briefing, objective. Translate the text values only. Markdown uses # for the story title and ## for mission titles.

Select English in the console, then click Reload stories & audio. If a language has no stories, Free mission remains available. No automatic machine translation is performed.
