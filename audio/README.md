# 本地音景

将 PCM WAV 文件放入此文件夹，刷新后在控制台选择。任务期间连续循环，暂停、中止、完成和退出时停止。默认静音。支持一小时以上 WAV；短片段循环不等于一小时原始音轨。

已检索到可下载素材入口（2026-10-20）：

- https://opengameart.org/content/50-cc0-sci-fi-sfx — CC0，包含终端等科幻音效。
- https://opengameart.org/content/60-cc0-sci-fi-sfx — CC0 科幻音效包。
- https://opengameart.org/content/sci-fi-sounds — CC0 科幻音效。
- https://freesound.org/people/qubodup/sounds/212025/ — 科幻实验室环境，CC BY 3.0，需保留来源与署名。

这些是素材来源，不是已经验证时长达到一小时的成品。当前没有捆绑下载音频；战争、解密、骇客、潜行四类一小时成品音景尚待制作或选择。程序已提供本地播放接口。音量使用 Windows 音量混合器调整。
